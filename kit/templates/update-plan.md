## Hypothesis log

| Date | Worst stat right now | Change | We expect | Read on | Result | Keep or revert |
|---|---|---|---|---|---|---|
| | | | stat X moves from A to B | date at least 7 days later | | |

Rules for this table:

1. One stat per update. If two things change, nobody knows which one worked.
2. The stat is the worst step of the funnel, not the one that is most interesting to work on.
3. Write the expected number before shipping.
4. Read the result only after the data window has passed. Roblox dashboards lag and rankings use rolling windows.
5. If the stat did not move, revert, unless there is another reason to keep the change.
